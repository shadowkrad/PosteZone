Formato CSV Richiesto

Il file deve essere in formato CSV delimitato da virgola (,) o punto e virgola (;) ed includere le seguenti colonne in ordine:

via;localita;tipo_civico;da_civico;a_civico;zona_sigla;barcode VIA ROMA;MILANO;TUTTI;;;ZONA-A; VIA MILANO;MILANO;PARI;;;ZONA-B; VIA MILANO;MILANO;DISPARI;;;ZONA-C; CORSO VITTORIO EMANUELE;MILANO;INTERVALLO;1;50;ZONA-A; VIA DANTE;MILANO;DISPARI_INTERVALLO;1;99;ZONA-B; VIA LEOPARDI;MILANO;TUTTI;;;ZONA-D;800123456789

* `tipo_civico` può assumere i valori: `TUTTI`, `PARI`, `DISPARI`, `INTERVALLO`, `PARI_INTERVALLO`, `DISPARI_INTERVALLO` (gli ultimi due limitano l'intervallo ai soli civici pari o dispari). Prima di ogni importazione viene salvata una copia di sicurezza del database.

* `barcode` è facoltativo e serve per abbinare un codice a barre direttamente a una zona.
